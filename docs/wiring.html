Rules and open items

Speaker wires

Amp outputs go only to a speaker. Never connect + or − to GND. Keep speaker wires away from the mic bundles.

Mic clock wires

Reconnect mic CLK wires only with the USB unplugged. The mics must start at the slow clock first, and the code does that on every start.

Volume

10% start, 14% hard cap in code, 1 s fade-in, sound only while the Mac is recording.

Open

The heat-damaged speaker has not been re-tested since the clock fix. In the first sweep, output above about 30 kHz fell off steeply, which still needs a careful measurement.
